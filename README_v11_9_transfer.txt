SwitchCare v11.9 - 領用備註、移撥出／移撥入（含外單位首次移入）

本版新增：
1. 領用清單與設備履歷週期顯示目前領用對象／單位及領用備註；領用備註獨立存放，不覆蓋設備主檔備註。
2. 移撥出：本處在庫設備移交其他區處；停止本處充電週期並從本處庫存統計排除。
3. 移撥入（既有設備）：先前已移撥出的設備移回本處，保留原有設備及歷史紀錄，依移撥入日期重新起算6個月。
4. 移撥入（外單位新設備）：可直接輸入10位料號、台電編號、型式、評價、倉庫、儲位、日期、來源單位、單號及備註；資料庫同一交易建立設備主檔、移撥履歷、Audit Log及第一個充電週期。
5. 台電編號重複檢查由資料庫唯一限制與RPC雙重保護。
6. 儀表板新增可點擊的移撥出／移撥入統計；移撥入清單包含目前仍屬本處管理的移入設備，不限於在庫狀態。
7. 移撥履歷顯示來源單位、接收單位、日期、單號及備註。

部署順序：
1. 先備份 Supabase 資料。
2. 在 Supabase SQL Editor 執行 database/v11_9_transfer_migration.sql 一次。
3. GitHub Pages 更新 app.js、index.html；保留 config.js，不要覆蓋 Supabase URL 與 Publishable Key。
4. 登入後測試一般領用、退庫、既有設備移撥出／移撥入、外單位首次移撥入及履歷查詢。

資料安全：
- Migration 不刪除 switches、usage_records、charge_records、audit_log 等既有資料表或資料。
- 新設備移撥入採單一資料庫交易；任一寫入失敗，整筆交易回滾。
- 尚未在實際 Supabase 專案執行 Migration；正式部署前須先在備份或測試環境執行並驗證。
