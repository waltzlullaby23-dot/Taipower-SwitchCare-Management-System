# SwitchCare v9.3 修正摘要

這版不再沿用前幾版逐筆補丁的做法。

## 已處理

1. JavaScript 變數統一：
   - CYCLE_MONTHS
   - REMIND_DAYS
   - SUPABASE_URL
   - SUPABASE_KEY

2. 登入：
   - 直接使用 Supabase Auth REST API
   - access_token / refresh_token
   - 自動刷新 Session
   - 所有 HTTP headers 經 Latin-1 安全檢查

3. 資料庫：
   - switches
   - charge_records
   - usage_records
   - audit_log

4. 業務交易：
   - create_switch
   - update_switch_master
   - issue_switch
   - return_switch
   - send_switch_for_charge
   - complete_switch_charge

5. 6個月規則：
   - 入帳日＋6個月
   - 領用停止
   - 退庫日重新起算
   - 充電完成日重新起算

## 如果 GitHub 仍顯示舊版本

1. 確認 Repository 中的 `index.html`、`app.js`、`style.css`、`config.js` 都是 v9.3。
2. 等 Actions / Pages deployment 完成。
3. Chrome Ctrl+F5。
4. 必要時開無痕視窗測試。

## 如果 v9.3 登入成功但資料查詢失敗

請到 SwitchCare → 系統設定 → 測試資料庫。
畫面會直接顯示 API 錯誤。

## 如果新增仍失敗

v9.3 不會只顯示「儲存失敗」，而會把 PostgreSQL / PostgREST 回傳的訊息顯示在表單內。
